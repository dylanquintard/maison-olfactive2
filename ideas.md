# Maison Olfactive — Exploration des directions de design

## Contexte
Marque artisanale de bougies, encens et objets parfumés. Univers : cuisine, saisons, matières brutes, souvenirs de maison. Palette : terracotta, crème vanille, brun miel, vert sauge, ivoire chaud. Typographie : serif éditoriale + sans-serif contemporaine.

## Direction A — Éditorial Brutaliste Doux

**Design Movement:** Post-Brutalisme Sensoriel — structures asymétriques avec chaleur organique

**Core Principles:**
- Grilles brisées et compositions en tension créative
- Textures de papier et grain photographique intégrés dans le CSS
- Typographie en taille extrême pour les titres, presque sculpturale
- Contraste entre la rigueur structurelle et la douceur des matières

**Color Philosophy:** Fond ivoire très chaud (#FBF6EE) avec des blocs terracotta (#C97C5D) qui "coupent" la page de façon inattendue. Le brun profond (#3D2A22) pour les textes. L'idée : une chaleur qui surprend.

**Layout Paradigm:** Colonnes de largeur inégale (3:7, 4:6), textes qui débordent sur les images, numéros de section en très grand format en arrière-plan, sections qui se chevauchent légèrement.

**Signature Elements:**
- Numéros de collection en très grand format, transparents, en arrière-plan
- Lignes horizontales fines en terracotta qui traversent la page
- Photos qui "sortent" de leurs conteneurs

**Interaction Philosophy:** Hover qui révèle une texture de cire ou de papier. Scroll parallaxe sur les images d'ambiance.

**Animation:** Entrées par glissement horizontal décalé. Textes qui apparaissent mot par mot. Transitions de page avec fondu crème.

**Typography System:** Cormorant Garamond (700, très grand) pour les titres / DM Sans (400) pour le corps. Titres en minuscules élégantes.

## Direction B — Maison Vivante (Retenue Sensorielle)

**Design Movement:** Artisanat Contemporain Japonais — wabi-sabi occidental, matières apparentes

**Core Principles:**
- Espace respirant généreux, jamais vide mais jamais surchargé
- Asymétrie subtile : les éléments ne sont jamais parfaitement centrés
- Les images sont les protagonistes, le texte les accompagne
- Rythme lent : le site se déroule comme une page de magazine

**Color Philosophy:** Fond ivoire chaud (#FBF6EE) dominant. Accents terracotta (#C97C5D) utilisés avec parcimonie, comme une épice. Le vert sauge (#A8B29A) pour les moments végétaux. Textes en brun profond (#3D2A22).

**Layout Paradigm:** Navigation latérale fine et discrète sur desktop. Sections en pleine largeur alternant avec des blocs éditoriaux en deux colonnes déséquilibrées. Les cartes produits flottent dans un espace généreux.

**Signature Elements:**
- Séparateurs en trait fin terracotta, légèrement inclinés
- Micro-animations de fumée en SVG sur les titres de collection
- Fond texturé papier en CSS (bruit subtil)

**Interaction Philosophy:** Tout est doux. Les hovers sont des transitions de 400ms. Les boutons n'ont pas de bordures agressives — juste un soulignement qui se dessine.

**Animation:** Apparition au scroll avec fade + légère montée (translateY 20px). Parallaxe sur les images hero. Curseur personnalisé (flamme discrète).

**Typography System:** Playfair Display (400 italic, 700) pour les titres / Jost (300, 400) pour le corps. Interlignage 1.8 pour le corps.

## Direction C — Chaleur Architecturale

**Design Movement:** Modernisme Organique — Alvar Aalto rencontre une cuisine provençale contemporaine

**Core Principles:**
- Formes courbes et organiques dans les conteneurs (pas de coins droits)
- Superposition de couches de chaleur : fond + texture + image + texte
- Navigation immersive : on entre dans la marque dès le premier scroll
- Chaque section est une "pièce" de la maison

**Color Philosophy:** Dégradés très subtils entre ivoire (#FBF6EE) et crème vanille (#F4E7D3). Blocs terracotta (#C97C5D) en formes organiques (blobs CSS). Brun miel (#A56E43) pour les accents structurels.

**Layout Paradigm:** Sections en pleine hauteur avec scroll snapping doux. Chaque "pièce" a sa propre ambiance colorée. Navigation par points discrets sur le côté.

**Signature Elements:**
- Blobs CSS organiques en terracotta semi-transparent derrière les images
- Textures de grain en overlay sur toutes les sections
- Icônes dessinées à la main (flamme, feuille, vapeur) en SVG

**Interaction Philosophy:** Le site réagit au scroll comme une respiration. Les sections s'ouvrent doucement, les produits apparaissent avec une légère rotation.

**Animation:** Scroll-triggered avec GSAP-like (framer-motion). Rotation légère à l'entrée (rotate -2deg → 0). Fond qui change de teinte selon la section active.

**Typography System:** Libre Baskerville (400, 700 italic) pour les titres / Outfit (300, 400, 500) pour le corps. Titres avec letter-spacing négatif.
</text>

## Direction choisie : **B — Maison Vivante (Retenue Sensorielle)**

Raison : Elle correspond le mieux à l'ADN de la marque — chaleur sans ostentation, éditorial sans lourdeur, commerce sans pression. L'asymétrie subtile et le rythme lent incarnent exactement la promesse de la marque : "une présence olfactive douce, sincère et mémorable."
